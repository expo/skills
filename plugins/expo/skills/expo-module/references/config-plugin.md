# Config Plugins for Expo Modules

Config plugins customize the native projects generated by `npx expo prebuild`: synchronous functions that take an `ExpoConfig` and return a modified one, named with a `with` prefix (`withMyConfig`).

> **Source of truth:** https://docs.expo.dev/config-plugins/introduction/ — consult the canonical docs when API details matter (`withInfoPlist`, `withAndroidManifest`, `AndroidConfig` helpers, mods, dangerous mods, `app.json` plugin syntax). For the module-embedded plugin walkthrough: https://docs.expo.dev/modules/config-plugin-and-native-module-tutorial/.

## Plugin Structure Inside a Module

```
my-module/
  plugin/
    tsconfig.json
    src/
      index.ts          # ConfigPlugin functions
  app.plugin.js         # Entry: module.exports = require('./plugin/build');
```

## Key Rules

- Plugins must be synchronous; return values must be serializable (except `mods`)
- `Mods` are async functions invoked during the prebuild "syncing" phase
- Use `npm run build plugin` to compile TypeScript plugins
- Test with `npx expo prebuild --clean`

## Reading Plugin-Written Values in Native Code

iOS — read an `Info.plist` key written via `withInfoPlist`:

```swift
Function("getApiKey") {
  return Bundle.main.object(forInfoDictionaryKey: "MY_API_KEY") as? String
}
```

Android — read `meta-data` written via `AndroidConfig.Manifest.addMetaDataItemToMainApplication`:

```kotlin
Function("getApiKey") {
  val appInfo = appContext?.reactContext?.packageManager?.getApplicationInfo(
    appContext?.reactContext?.packageName.toString(),
    PackageManager.GET_META_DATA
  )
  return@Function appInfo?.metaData?.getString("MY_API_KEY")
}
```

# Create a base image

1. Isolate the selected tile at its native resolution and exclude the number and any neighboring cells. If the selected concept is already a standalone image, use it directly. Ask for the tile number if the sheet has multiple options and the user has not chosen one.
2. Use the isolated concept as the image-editing reference. Request one high-resolution lossless WebP with alpha. If the tool returns a transparent PNG, encode it with `cwebp -lossless base.png -o base.webp` or an equivalent lossless encoder. Use a square canvas by default. Preserve the face, silhouette, limb lengths, palette, and pose. Leave enough room for the full character and its movement. Use the highest practical output resolution, or the requested size. If image generation is unavailable, explain how to enable it or ask for a high-resolution transparent source.
3. Decode the WebP and check that it has transparent pixels around the mascot and that the edges look clean against light and dark backgrounds. Compare it with the approved concept at the same visible scale. Redo the image if it changes the design or clips the silhouette.
4. Return the base WebP and record its canvas dimensions and character placement, including the grounded feet or equivalent baseline. Preserve this full canvas for the rig and outfit overlays. Use its top-left corner as the registration origin and record any scale or offset when placing it on the Rive artboard.
